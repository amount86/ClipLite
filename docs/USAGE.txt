ClipLite v0.7.2 改修版（2026-11-08）
===================================
- 起動時に実行ポリシーを変更しません。実行が許可された環境で使用してください。
- ダウンロードした未署名スクリプトはRemoteSignedでもブロックされる場合があります。
  職場では管理担当者に相談してください。インストール不要でも利用許可は別途必要です。
- 自動貼り付け直前に対象ウィンドウを再確認します。修飾キーを離さない場合は中止します。
- 設定の型・範囲を起動時に検証します。
- JSON保存は同じフォルダーの一時ファイルから置き換え、失敗時は定型文の編集を取り消します。
- 起動失敗ログには例外の型のみを記録します。

情報の扱い
----------
履歴をアプリがファイル保存することはありませんが、メモリの安全な消去は保証しません。
履歴の全消去・終了はWindowsの現在のクリップボードやWin+V履歴を消しません。
Windowsや他アプリによる履歴保存・同期は別の設定です。
定型文と保存時の一時ファイルは平文です。パスワードや機密情報を登録しないでください。
既存のClipLite-startup.logに旧版の情報が残る場合があります。公開物には含めないでください。
配布ZIPの定型文はサンプルのみです。手元の個人用templates.jsonは変更していません。

ClipLite v0.7.1
===============

概要
----
ClipLiteは、Windows PowerShell 5.1とWindows標準.NET Frameworkだけで動作する、
テキスト専用のクリップボード履歴・定型文ツールです。

外部モジュール、NuGetパッケージ、インストーラー、常駐EXEは使用しません。
クリップボード履歴はメモリ内だけに保持し、ファイルへ保存しません。
ClipLiteを終了すると、クリップボード履歴はすべて破棄されます。

主な機能
--------
- コピーしたテキストの一時的な履歴保持
- Ctrlキーを素早く2回押して、マウスカーソル付近に画面を表示
- 1〜9、0、a〜zの1キーで項目を即貼り付け
- Ctrl+1 / Ctrl+2 でタブ切り替え
- 履歴の検索、選択、削除、全消去
- 定型文の追加、編集、削除
- 定型文中の {{DATE}} を今日の日付へ変換
- 選択後、元のウィンドウのフォーカス位置へ戻して自動貼り付け
- 別のウィンドウへフォーカスが移ると自動で非表示
- ダーク配色のコンパクトな画面
- 前回選択したタブの復元
- タスクトレイ常駐
- 多重起動防止

対象環境
--------
- Windows 10またはWindows 11
- Windows PowerShell 5.1
- Windows標準.NET Framework
- PowerShellスクリプトとAdd-Typeの使用が認められている環境

ファイル構成
------------
ClipLite\
├─ ClipLite.ps1
├─ README.txt
├─ Start-ClipLite.cmd
├─ Start-ClipLite-Diagnostic.cmd
├─ execute.bat
├─ config.json
├─ templates.json
└─ ui-state.json

- クリップボード履歴用のhistory.jsonは作成しません。
- ClipLite.ps1はUTF-8(BOM付き)で保存してください。BOMがないと、
  Windows PowerShell 5.1では日本語が文字化けし、起動に失敗することがあります。

起動方法
--------
通常はStart-ClipLite.cmdまたはexecute.batを実行します。
正常に起動すると、タスクトレイにClipLiteのアイコンが表示されます。

起動できない場合はStart-ClipLite-Diagnostic.cmdを実行し、画面に表示される
エラーとClipLite-startup.logを確認してください。ClipLite-startup.logには
起動情報とエラーだけを記録し、クリップボード本文は記録しません。

画面の表示
----------
Ctrlキーを素早く2回押すと、マウスカーソル付近にClipLiteを表示します。

操作例:
  Ctrlを押す → 離す → Ctrlを押す → 離す

- 左Ctrl、右Ctrlのどちらでも使用できます。
- 初期値では、1回目のCtrlを離してから400ミリ秒以内に2回目のCtrlを離すと認識します。
- Ctrlを押している間、または1回目と2回目のCtrlの間に別のキーを押した場合は、
  通常のショートカットとして扱い、ダブルタップ判定を取り消します。
- 画面がモニターからはみ出す場合は、カーソルの左側または上側に表示位置を自動調整します。
  マルチモニター環境では、カーソルがあるモニターに表示します。
- タスクトレイアイコンのダブルクリックでも表示できます。

画面の構成
----------
  [クリップボード] [定型文]                  [×]
  ClipLite v0.7.1             履歴 12件 / 12件中
  [検索欄]
  1: 一覧の項目
  2: 一覧の項目
  ...
  0: 10件目
  a: 11件目
  ...
  (操作ヘルプ)

- 上部のボタンでタブを切り替えます(Ctrl+1 / Ctrl+2でも切り替えできます)。
- 2行目(タイトル行)をドラッグすると、ウィンドウを移動できます。
- 各項目の先頭に、1キー貼り付け用のキー(1〜9、0、a〜z)を表示します。
- 検索欄は履歴タブでのみ表示します。

基本操作
--------
画面を表示すると、前回選択したタブを開き、一覧の先頭を選択してフォーカスします。
表示するたびに検索欄は空に戻ります。

  キー                       動作
  -------------------------  ----------------------------------------
  1〜9、0、a〜z              該当する項目をすぐ貼り付け(先頭36件まで)
  上下カーソルキー           項目を選択
  Enter / ダブルクリック     選択項目を貼り付け
  Ctrl+1                     クリップボード(履歴)タブへ切り替え
  Ctrl+2                     定型文タブへ切り替え
  Ctrl+F                     検索欄へ移動
  Delete                     選択項目を削除
  Ctrl+Delete                履歴を全消去(履歴タブのみ)
  Esc / ×ボタン              画面を閉じ、元のウィンドウへ戻る

- 1キー貼り付けは、一覧にフォーカスがあるときに有効です。
  テンキーの数字も使用できます。
- 一覧で英字キーが貼り付け用に割り当てられているため、検索はCtrl+Fで
  検索欄へ移動してから入力してください。

画面が閉じるタイミング
----------------------
- 項目を貼り付けたとき
- EscキーまたはXボタンを押したとき
- 別のウィンドウをクリックするなどして、フォーカスが他へ移ったとき

定型文の編集ダイアログや削除の確認メッセージを表示している間は閉じません。

フォーカスの扱い
----------------
ClipLiteは、表示する直前のウィンドウと、その中で入力フォーカスを持っていた
位置(入力欄やセルなど)を記録します。

- 貼り付け時、またはEsc・Xで閉じたときは、記録した位置へフォーカスを戻します。
- 別のウィンドウをクリックして閉じた場合は、クリックしたウィンドウを優先し、
  元のウィンドウへは戻しません。
- Ctrl2回の判定は貼り付け先アプリへのキー入力を妨げないため、ブラウザ版Excelなどでも
  フォーカスが外れにくくなっています。

選択後の動作
------------
1. 選択した文字列をWindowsのクリップボードへ設定します。
2. ClipLiteを開く直前のウィンドウとフォーカス位置へ戻します。
3. ClipLite画面を隠します。
4. Ctrlなどの修飾キーが離されるのを待ってから、Ctrl+Vを自動送信します。

貼り付け先が管理者権限で動作しているなど、ClipLiteと権限が異なる場合は
自動貼り付けできないことがあります。元のウィンドウへ戻せなかった場合は、
誤った場所への貼り付けを防ぐため、Ctrl+Vを送信しません。この場合も文字列は
クリップボードに設定されているため、手動でCtrl+Vを押せば貼り付けられます。

履歴(クリップボード)タブ
------------------------
- Ctrl+F → 入力   : 履歴を絞り込み(大文字・小文字を区別しない)
- 検索欄で↓       : 一覧へ移動
- 検索欄でEnter   : 先頭(選択中)の履歴を貼り付け
- Delete          : 選択した履歴を削除
- Ctrl+Delete     : 履歴を全消去

履歴項目へマウスポインターを合わせると、コピーした日時を表示します。
件数表示は「履歴 表示件数 / 全件数中」の形式です。
履歴は起動中のメモリ内だけに保持されます。

以下のタイミングで履歴は消去されます。
- タスクトレイから「履歴を全消去」を選択したとき
- Ctrl+Deleteを押したとき
- ClipLiteを終了したとき
- PCからサインアウトまたは再起動したとき

履歴をOneDriveやその他の保存場所へ書き出すことはありません。

定型文タブ
----------
追加:
1. 「定型文」タブを開きます(Ctrl+2)。
2. 「追加」を押します。
3. 名前と本文を入力します。
4. 「保存」を押します。

編集・削除:
- 対象を選び、「編集」または「削除」を押します。
- Deleteキーでも選択した定型文を削除できます。

使用:
- 定型文を選びEnterを押します。
- 定型文をダブルクリックします。
- 一覧の先頭に表示されたキー(1〜9、0、a〜z)を押します。

定型文はtemplates.jsonへ保存されます。OneDrive上に配置する場合、templates.jsonも
同期対象になるため、機密情報やパスワードを定型文として登録しないでください。

今日の日付を入れる
------------------
定型文の本文に次のトークンを記述します。

  {{DATE}}

使用時に、今日の日付をYYYY/MM/DD形式で挿入します。

登録例:
  本日（{{DATE}}）付で処理しました。

2026年7月29日に使用した結果:
  本日（2026/07/29）付で処理しました。

- templates.jsonには{{DATE}}のまま保存されます。
- 使用するたびに、その日のローカル日付へ変換します。
- 1つの定型文に複数の{{DATE}}を記述できます。
- 日付変換は定型文だけが対象です。

タスクトレイメニュー
--------------------
- 履歴を表示     : ClipLite画面を表示
- 監視を一時停止 : 新しい履歴の取り込みを停止
- 監視を再開     : 履歴取り込みを再開
- 履歴を全消去   : メモリ内の履歴を空にする
- 終了           : ClipLiteを終了し、履歴を破棄

設定ファイル
------------
config.jsonはClipLiteを終了してから編集してください。

主な項目:
- MaxHistory             メモリ内で保持する履歴の最大件数
- MaxTextLength          1件の最大文字数
- IgnoreDuplicate        重複履歴を1件にまとめる
- IgnoreWhitespaceOnly   空白だけの内容を除外
- PreviewLength          一覧プレビューの最大文字数
- AutoPaste              trueで選択後にCtrl+Vを自動送信
- DoubleCtrlThresholdMs  Ctrl2回押しの最大間隔。未設定時は400ミリ秒
- Window.Width           ウィンドウ幅
- Window.Height          ウィンドウ高さ
- Window.TopMost         最前面表示

補足:
- v0.7.0以降は枠なしウィンドウのため、マウスでのサイズ変更はできません。
  サイズはWindow.WidthとWindow.Heightで調整してください。
  目安は幅420、高さ560です(最小は幅320、高さ240)。
- 1キー貼り付けの対象は先頭36件です。それ以降の項目は上下キーで選択してください。

設定例:
  {
    "MaxHistory": 100,
    "MaxTextLength": 100000,
    "IgnoreDuplicate": true,
    "IgnoreWhitespaceOnly": true,
    "PreviewLength": 80,
    "AutoPaste": true,
    "DoubleCtrlThresholdMs": 400,
    "Window": {
      "Width": 420,
      "Height": 560,
      "TopMost": true
    }
  }

保存ファイル
------------
- templates.json        定型文。平文
- ui-state.json         前回選択したタブ
- ClipLite-startup.log  起動・エラー情報。クリップボード本文は含まない

history.jsonは使用しません。

実行ポリシー
------------
実行ポリシーがRestrictedの場合はClipLite.ps1を直接実行できません。
現在の設定は次のコマンドで確認できます。

  Get-ExecutionPolicy
  Get-ExecutionPolicy -List

旧版が変更した実行ポリシーを戻す場合は、変更前の設定を管理担当者へ確認してください。

職場PCでは組織の運用規程を優先してください。

旧バージョンからの更新
----------------------
1. 旧版のClipLiteをタスクトレイから終了します。
2. v0.7.1を新しいフォルダーへ展開します。
3. 定型文を引き継ぐ場合だけ、旧版のtemplates.jsonをコピーします。
4. 必要に応じてui-state.jsonとconfig.jsonをコピーします。
5. history.jsonはコピーしないでください。

v0.6.x以前のconfig.jsonを引き継ぐ場合は、新しい画面に合わせて
Window.WidthとWindow.Heightを見直してください。

旧フォルダーにhistory.jsonが残っている場合、v0.7.1は読み込みも更新も行いません。
history.jsonには旧版の履歴が平文で含まれている可能性があります。
不要であれば削除してください。

トラブルシューティング
----------------------
Ctrl2回で開かない:
- Ctrlを押して離す操作を素早く2回行ってください。
- 1回目と2回目のCtrlの間に他のキーを押していないか確認してください。
- DoubleCtrlThresholdMsを500または600へ増やしてください。
- タスクトレイアイコンから開いてください。
- ClipLite-startup.logにDoubleCtrlHookのエラーがないか確認してください。

貼り付けられない:
- 貼り付け先にカーソルがあるか確認してください。
- config.jsonのAutoPasteがtrueか確認してください。
- AutoPasteをfalseにし、選択後に手動でCtrl+Vを試してください。
- 貼り付け先が管理者権限で動作していないか確認してください。

ブラウザ版Excelなどで貼り付けが失敗することがある:
- 貼り付け先がフォーカスを受け取るまでの待ち時間が不足している可能性があります。
  ClipLite.ps1のPaste-TextToPreviousWindow内にある
  「Start-Sleep -Milliseconds 120」を200程度に増やしてください。

1キー貼り付け(a〜zなど)が効かない:
- 一覧にフォーカスがあるか確認してください。検索欄にフォーカスがある場合は
  文字入力として扱われます。↓キーで一覧へ移動してください。
- IMEがオンの場合、キー入力が変換に使われることがあります。
  数字キー、またはIMEをオフにした状態でお試しください。

画面がすぐ消える / 消えない:
- 別のウィンドウへフォーカスが移ると自動で閉じる仕様です。
- 定型文の編集中や確認メッセージの表示中は閉じません。

定型文の日付が変換されない:
- 半角文字で{{DATE}}と入力してください。
- 波括弧を2個ずつ使用してください。

定型文を保存できない:
- templates.jsonが読み取り専用でないか確認してください。
- ClipLiteフォルダーへの書き込み権限を確認してください。

日本語が文字化けする / 起動時に構文エラーになる:
- ClipLite.ps1をUTF-8(BOM付き)で保存し直してください。

終了と削除
----------
タスクトレイアイコンを右クリックし、「終了」を選択します。
終了時、メモリ内のクリップボード履歴はすべて破棄されます。

削除する場合は終了後にClipLiteフォルダーを削除してください。
必要であればtemplates.jsonとconfig.jsonだけを事前にバックアップしてください。
